Detailed Description

v3: Sample allocations using the built-in pprof-compatible profiler or custom profiling hooks.

Include <mimalloc-profile.h> and build with profiling support (-DMI_PROFILE=ON). The profiling API is experimental and may still change.

Programmatic profiling

Explicit profiler APIs remain available in secure builds and when environment-based activation is disabled. Create a profiler, attach it, and then start sampling:

#include <mimalloc.h>
#include <mimalloc-profile.h>
int main(void) {
mi_profiler_t* prof = mi_pprof_profiler_new(
512 * 1024, // sample roughly every 512 KiB
"myprofile", // output basename; protobuf format
0, 0, 0); // no automatic snapshots
if (prof == NULL) return 1;
if (!mi_profile(prof)) {
mi_profile(NULL);
mi_pprof_profiler_delete(prof);
return 1;
}
mi_profiler_start(prof);
// Run your workload here; join worker threads before cleanup.
mi_profiler_stop(prof);
mi_profiler_snapshot(prof);
mi_profile(NULL); // detach before deleting
mi_pprof_profiler_delete(prof);
return 0;
}

Stopping sampling does not detach the profiler: its on_free callback can still be invoked for sampled allocations. Before deleting a profiler, detach it from all associated heaps and subprocesses, and ensure no other thread can still invoke its callbacks.

Environment-based profiling

When both MI_SECURE=0 and MI_SECURE_ENV=0, MIMALLOC_PROFILE=<basename> activates the built-in profiler for the main subprocess. Elevated processes ignore this environment variable regardless of build settings.

  • MIMALLOC_PROFILE_SAMPLE_RATE: approximate number of allocated bytes between samples (default: 512KiB).
  • MIMALLOC_PROFILE_ALLOC_INTERVAL: allocated bytes between automatic snapshots (default: 1GiB; 0 disables).
  • MIMALLOC_PROFILE_INUSE_INTERVAL: growth in in-use bytes between automatic snapshots (default: 0, disabled).
  • MIMALLOC_PROFILE_TIME_INTERVAL: seconds between automatic snapshots, checked on allocation events (default: 0, disabled).

Snapshots use protobuf format by default. A basename ending in .Heaps or .text selects the text heap-profile format instead.

Parameters
initial_thresholdApproximate number of allocated bytes between samples (for example, 512 * 1024).
base_file_nameOutput basename. A .Heaps or .text extension selects text format; any other extension, or none, selects protobuf format. A filename extension is stripped.
alloc_interval_sizeAllocated bytes between automatic snapshots, or 0 to disable.
inuse_interval_sizeGrowth in in-use bytes between automatic snapshots, or 0 to disable.
time_interval_secsSeconds between automatic snapshots, or 0 to disable. Time intervals are checked on allocation events, not by a background timer.
Returns
A profiler, or NULL on failure. The returned profiler must be attached and started before it samples allocations.
