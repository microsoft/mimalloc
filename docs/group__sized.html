Detailed Description

v3: Allocate or free memory while reporting the allocator's block size in bytes.

Reported sizes may include padding or alignment overhead and are not a guarantee of writable capacity. Size output pointers may be NULL. Allocation size outputs are only valid on success; they need not be cleared on failure.
