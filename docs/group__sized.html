Detailed Description

v3: Allocate or free memory while reporting the usable size in bytes.

The reported size always equals mi_usable_size() of the returned (or freed) pointer, and can be used as the writable capacity. Size output pointers may be NULL. Allocation size outputs are only valid on success; they need not be cleared on failure.
